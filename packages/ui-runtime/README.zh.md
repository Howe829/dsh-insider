# @deepseek-ai/dsh-client-ui-runtime

[English](README.md) | 中文

`dsh-insider` 的浏览器界面。该 Client Cordis 插件注册一个 `sidebar.footer` 操作和一个 `shell.overlay`。打开操作后，探查器会贴着当前侧边栏展开为全高界面；关闭后回到原有 DSH 界面，不会增加悬浮助手按钮，也不会取代会话 UI。标题栏会显示 Host 快照提供的精确当前 profile。

「运行时图」将 Host 快照渲染为确定性的「提供方→消费方」依赖图。状态卡片和筛选器只使用四个稳定的产品状态：等待中、活跃、已释放和失败；详细 Loader 阶段会归并到这四种状态。默认画布保持插件与服务主图简洁；选中插件或按 Fiber 状态筛选时，才按需展开具体 Fiber、插件归属、父子 Fiber 和缺失注入关系。搜索同时覆盖 Fiber uid、名称与模块。总览中的 Fiber 状态卡片会进入 Fiber 模式，因此即使所属插件处于活跃状态，也能定位其中等待中的子 Fiber。有界缩放控件可以缩放画布并重置视口。在画布空白处拖动会平移整张依赖图，而不会抢走节点点击；视口获得焦点后仍保留原生键盘滚动。选中节点后，画布只保留它完整的关系邻域并打开右侧详情；关闭详情会恢复完整依赖图。

「总览」包含一个基于 Host 有界 Effect 生命周期窗口的紧凑 Plugin Activity 表。每行同时展示 Current、Delta、Churn 与当前数量迷你趋势图，使稳定持有、高周转和持续增长彼此可区分。选中一行后可查看 Created、Disposed、Net、Churn、更大的趋势图，以及只包含安全标签的最近 Effects。窗口发生溢出时，界面会标记数据不完整，而不会把部分变化伪装成完整历史。

「请求追踪」先把 Host 的有界元数据窗口分组为 Session 所属的 Agent Turn。选中 Turn 后打开按时间排序的用户、Agent loop、LLM、工具和会话轨道；再选中单个事件时只显示其关联字段。没有 Turn 的事件仍计为会话级事件，不会被分配到虚构的 Turn。若某个保留 Turn 的开始事件已落在有界窗口之外，界面会将其标为数据不完整。界面文案明确说明其中不含提示词、模型输出、工具参数或工具结果内容。一个共享的可观察 Remote 数据源负责单飞刷新，只在浮层可见时按 Host 返回的间隔轮询。

本包使用既有的 locale、runtime、sidebar、layout、slot 与 ui-primitives 契约。它的公开注册全部通过 Cordis effects 完成，因此 Client 插件卸载时会一并移除入口、浮层、语言贡献、数据源与 store。

## 模型体验

无，因为这个仅浏览器使用的诊断界面只可视化元数据，不注册任何模型能力。

#### KV Cache 影响

无；它既不读取也不改变模型输入。

## 已知限制与暂缓事项

- 依赖图使用确定性分列布局，关闭浮层后不会保留缩放比例或视口位置。
- 浏览器轮询当下快照，而不是订阅 Host 推送流。
- 追踪历史仅限当前 Host 进程及其已配置的保留窗口。
- Effect 活动从 Host 插件激活时开始，仅存在于当前进程，并排除无法归属到 Loader 条目的 Effects。
- 该界面只读，不提供插件生命周期控制。
